# ManipSec-Gen

ManipSec-Gen converts verified failures from ManipSec-ART into security training data.

## Failure Collection

Collect attacks that compromise a generated policy.

## Secure Correction

Generate a corrected policy or response for each failure.

## Data Verification

Keep corrections that complete the task without triggering the attack objective.

## Model Training

Use verified failure-correction pairs for security fine-tuning.
