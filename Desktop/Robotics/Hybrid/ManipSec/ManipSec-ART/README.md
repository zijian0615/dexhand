# ManipSec-ART

ManipSec-ART evaluates frontier coding agents on ManipSec-Bench.

## Policy Generation

Each coding agent receives a task and the policy interface, then writes executable policy code.

## Clean Evaluation

Run the generated policy on clean task instances and measure TSR.

## Adversarial Evaluation

Run the same policy on matched attacked instances and measure SSR and ASR.

## Security Analysis

Compare agents by task competence, attack robustness, and failure type.
